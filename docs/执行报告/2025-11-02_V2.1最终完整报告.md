## 📋 改进概述

### 目标
在港股公告分析系统的ClickHouse数据库中，为**2张核心表**新增分类字段，以支持完整的港交所文档层级分类，并移除不需要的section_entities表。

### 改进范围

| 表名 | 改进内容 | 状态 |
|------|---------|------|
| `documents_v2` | 新增3个分类字段 + 1个全文检索索引 | ✅ 完成 |
| `document_sections` | 新增2个分类字段 | ✅ 完成 |
| `section_entities` | 移除（用户反馈不需要） | ✅ 完成 |

---

## 🎯 改进详情

### 1. documents_v2 表（文档元信息表）

#### 新增字段（3个）

| 字段名 | 类型 | 默认值 | 说明 | 示例 |
|--------|------|--------|------|------|
| `announcement_title` | `String` | `''` | 公告标题（从文件名提取） | `有關委任獨立非執行董事之補充公告` |
| `document_category` | `LowCardinality(String)` | `''` | 文档主分类（目录一级） | `公告及通告`、`通函` |
| `announcement_category` | `LowCardinality(String)` | `''` | 公告子分类（目录二级） | `更換董事或重要行政職能或職責的變更` |

#### 新增索引（1个）

| 索引名 | 类型 | 字段 | 用途 |
|--------|------|------|------|
| `idx_ann_title` | `tokenbf_v1(10240, 3, 0)` | `announcement_title` | 标题全文检索 |

#### 字段总数
- **V2.0**: 18个字段
- **V2.1**: 21个字段 ✅

## 📈 查询能力提升

### 1. 文档表查询示例

#### 按主分类统计
```sql
SELECT 
    document_category AS 分类,
    count() AS 数量,
    sum(page_count) AS 总页数
FROM hkex_analysis.documents_v2
WHERE stock_code = '00328'
GROUP BY 分类
ORDER BY 数量 DESC;
```

#### 查找董事变动公告
```sql
SELECT 
    announcement_date,
    announcement_title,
    page_count
FROM hkex_analysis.documents_v2
WHERE stock_code = '00328'
  AND announcement_category = '更換董事或重要行政職能或職責的變更'
ORDER BY announcement_date DESC;
```

#### 标题全文检索
```sql
SELECT 
    announcement_date,
    document_category,
    announcement_title
FROM hkex_analysis.documents_v2
WHERE stock_code = '00328'
  AND announcement_title LIKE '%獨立非執行董事%'
ORDER BY announcement_date DESC;
```

### 2. 章节表查询示例

#### 按分类查询章节
```sql
SELECT 
    document_category,
    section_type,
    section_title,
    char_count
FROM hkex_analysis.document_sections
WHERE stock_code = '00328'
  AND document_category = '公告及通告'
ORDER BY created_at DESC
LIMIT 10;
```

#### 冗余字段避免JOIN
```sql
-- 改进前（需要JOIN）
SELECT s.section_title, d.document_category
FROM document_sections s
JOIN documents_v2 d ON s.doc_id = d.doc_id
WHERE d.document_category = '公告及通告';

-- 改进后（无需JOIN）
SELECT section_title, document_category
FROM document_sections
WHERE document_category = '公告及通告';
```

## 💡 技术亮点

### 1. LowCardinality 优化

**优势**:
- 自动编码：将字符串转为整数编码
- 内存优化：降低内存占用
- 查询加速：等值查询和GROUP BY自动优化
- 无需索引：性能已足够好

**适用场景**:
- 枚举类型字段（如分类字段）
- 低基数字段（不同值数量少）

### 2. tokenbf_v1 全文检索索引

**优势**:
- 支持LIKE模糊查询加速
- 布隆过滤器快速过滤
- 参数可调优

**配置**:
```sql
tokenbf_v1(10240, 3, 0)
-- 10240: 布隆过滤器大小
-- 3: 哈希函数数量
-- 0: token提取器类型
```

### 3. 冗余字段设计

**优势**:
- 避免频繁JOIN操作
- 加速分类筛选查询
- 降低查询复杂度

**场景**:
- `document_sections` 表冗余存储 `document_category` 和 `announcement_category`
- 直接查询章节表即可按分类过滤，无需JOIN `documents_v2`
