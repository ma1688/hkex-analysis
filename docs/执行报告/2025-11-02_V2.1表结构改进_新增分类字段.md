# V2.1 表结构改进报告 - 新增3个分类字段

**执行日期**: 2025-11-02  
**版本**: documents_v2 V2.0 → V2.1  
**改进类型**: 表结构扩展（向后兼容）

---

## 📋 改进概述

### 目标
在现有 `documents_v2` 表基础上，新增3个分类字段以支持完整的港交所文档层级分类，提升查询能力和业务表达力。

### 新增字段（3个）

| 字段名 | 数据类型 | 默认值 | 说明 | 示例 |
|--------|---------|--------|------|------|
| `document_category` | `LowCardinality(String)` | `''` | 文档主分类（目录一级） | `公告及通告`、`通函` |
| `announcement_category` | `LowCardinality(String)` | `''` | 公告子分类（目录二级） | `更換董事或重要行政職能或職責的變更` |
| `announcement_title` | `String` | `''` | 公告标题（从文件名提取） | `有關委任獨立非執行董事之補充公告` |

### 新增索引（3个）

| 索引名 | 字段 | 类型 | 用途 |
|--------|------|------|------|
| `idx_doc_category` | `document_category` | `set` | 加速按主分类查询 |
| `idx_ann_category` | `announcement_category` | `set` | 加速按子分类查询 |
| `idx_ann_title` | `announcement_title` | `tokenbf_v1` | 支持标题全文检索 |

### Step 2: 更新数据导入脚本

**文件**: `scripts/chunk_pdf_by_sections.py`

**修改内容**:

#### 2.1 新增字段提取方法

```python
def extract_category_fields(self) -> Dict:
    """从文件路径提取分类字段（新增）"""
    parts = self.pdf_path.parts
    
    try:
        hkex_idx = parts.index('HKEX')
        # 文档主分类：HKEX/股票代码/【这一层】
        document_category = parts[hkex_idx + 2] if len(parts) > hkex_idx + 2 else ''
        # 公告子分类：HKEX/股票代码/主分类/【这一层】
        announcement_category = parts[hkex_idx + 3] if len(parts) > hkex_idx + 3 else ''
    except (ValueError, IndexError):
        document_category = ''
        announcement_category = ''
    
    # 从文件名提取公告标题
    filename = self.pdf_path.stem
    match = re.match(r'\d{4}-\d{2}-\d{2}_\d+_[^_]+_(.*)', filename)
    announcement_title = match.group(1).replace('n', ' ') if match else filename
    
    return {
        'document_category': document_category,
        'announcement_category': announcement_category,
        'announcement_title': announcement_title
    }
```

#### 2.2 更新插入逻辑

## 🎯 改进效果

### 1. 增强的查询能力

#### 查询示例1：按主分类统计
```sql
SELECT 
    document_category,
    count() AS 文档数量,
    sum(page_count) AS 总页数
FROM documents_v2
WHERE stock_code = '00328'
GROUP BY document_category
ORDER BY 文档数量 DESC;
```

#### 查询示例2：查找董事变动公告
```sql
SELECT 
    announcement_date,
    announcement_title,
    page_count
FROM documents_v2
WHERE stock_code = '00328'
  AND announcement_category = '更換董事或重要行政職能或職責的變更'
ORDER BY announcement_date DESC;
```

#### 查询示例3：标题全文检索
```sql
SELECT 
    announcement_date,
    document_category,
    announcement_title
FROM documents_v2
WHERE stock_code = '00328'
  AND announcement_title LIKE '%獨立非執行董事%'
ORDER BY announcement_date DESC;
```

#### 查询示例4：统计2025年公告分布
```sql
SELECT 
    document_category AS 主分类,
    announcement_category AS 子分类,
    count() AS 数量
FROM documents_v2
WHERE stock_code = '00328'
  AND toYear(announcement_date) = 2025
GROUP BY 主分类, 子分类
ORDER BY 主分类, 数量 DESC;
```

### 2. 业务表达力提升

**改进前**:
- 只能按 `document_type` 区分（rights/placing/ipo/consolidation）
- 无法区分不同的公告类型
- 无法按目录结构分类

**改进后**:
- 完整保留港交所文档层级结构（主分类+子分类）
- 支持按公告类型精准查询
- 公告标题可全文检索

### 3. 性能优化

- 新增3个索引加速常用查询
- `LowCardinality` 优化枚举类型存储
- 标题全文检索使用 `tokenbf_v1` 布隆过滤器
