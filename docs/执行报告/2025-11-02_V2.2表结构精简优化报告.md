## 📝 优化后的表结构

### documents_v2 表（精简版）

```sql
CREATE TABLE IF NOT EXISTS documents_v2 (
    -- 主键
    doc_id String,
    
    -- 核心信息
    announcement_title String DEFAULT '',           -- 公告标题
    stock_code LowCardinality(String),              -- 股票代码
    company_name String DEFAULT '',                 -- 公司名称
    
    -- 分类信息
    document_category LowCardinality(String) DEFAULT '',    -- 文档主分类
    announcement_category LowCardinality(String) DEFAULT '', -- 公告子分类
    document_type LowCardinality(String),           -- 业务类型
    
    -- 时间和文件
    announcement_date Date,                         -- 公告日期
    file_path String,                               -- 文件路径
    page_count UInt32 DEFAULT 0,                    -- PDF页数
    
    -- 扩展字段
    metadata String DEFAULT '{}',                   -- JSON扩展
    created_at DateTime DEFAULT now()               -- 创建时间
    
) ENGINE = MergeTree()
ORDER BY (stock_code, announcement_date, doc_id)
PRIMARY KEY (stock_code, announcement_date, doc_id)
COMMENT '文档元信息表V2.2 - 精简优化版';
```

### document_sections 表（精简版）

```sql
CREATE TABLE IF NOT EXISTS document_sections (
    -- 主键
    section_id String,
    doc_id String,
    
    -- 分类信息（冗余，避免JOIN）
    document_category LowCardinality(String) DEFAULT '',
    announcement_category LowCardinality(String) DEFAULT '',
    section_type LowCardinality(String),
    
    -- 章节结构
    section_title String,
    section_index UInt32,
    page_start UInt32,
    page_end UInt32,
    
    -- 内容
    content String,
    
    -- 优先级
    priority UInt8 DEFAULT 1,
    
    -- 扩展字段
    metadata String DEFAULT '{}',
    created_at DateTime DEFAULT now()
    
) ENGINE = MergeTree()
ORDER BY (doc_id, section_index)
PRIMARY KEY (doc_id, section_index)
COMMENT '文档章节表V2.2 - 精简优化版';
```

## 🔍 查询适配指南

### 1. 计算字段替代

#### section_count（章节总数）

**优化前**:
```sql
SELECT section_count FROM documents_v2 WHERE doc_id = 'xxx';
```

**优化后**:
```sql
SELECT count() FROM document_sections WHERE doc_id = 'xxx';
```

#### total_chars（总字符数）

**优化前**:
```sql
SELECT total_chars FROM documents_v2 WHERE doc_id = 'xxx';
```

**优化后**:
```sql
SELECT sum(length(content)) FROM document_sections WHERE doc_id = 'xxx';
```

#### char_count（章节字符数）

**优化前**:
```sql
SELECT char_count FROM document_sections WHERE section_id = 'xxx';
```

**优化后**:
```sql
SELECT length(content) FROM document_sections WHERE section_id = 'xxx';
```

### 2. 元数据迁移

如需使用被删除字段，可放入metadata JSON：

```sql
-- 示例：将 document_subtype 放入 metadata
UPDATE documents_v2 
SET metadata = JSONSet(metadata, 'document_subtype', 'underwritten')
WHERE doc_id = 'xxx';

-- 查询
SELECT JSONExtractString(metadata, 'document_subtype') AS subtype
FROM documents_v2;
```
