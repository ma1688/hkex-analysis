## 📊 性能优化说明

### LowCardinality 优势

`document_category` 和 `announcement_category` 使用 `LowCardinality` 类型的优势：

1. **自动编码**: ClickHouse自动将字符串转为整数编码
2. **内存优化**: 降低内存占用
3. **查询加速**: 等值查询和GROUP BY自动优化
4. **无需额外索引**: 性能已足够好，不需要额外的set索引

### 全文检索索引

`announcement_title` 使用 `tokenbf_v1` 布隆过滤器索引：

1. **支持LIKE查询**: `LIKE '%keyword%'` 快速过滤
2. **参数说明**: 
   - 10240: 布隆过滤器大小
   - 3: 哈希函数数量
   - 0: token提取器类型（默认）
3. **性能提升**: 大幅加速标题模糊匹配
