# CLI中断优化使用指南

## ✨ 新特性

经过优化，CLI的`ask`和`chat`命令现在支持**快速中断**：
- ⚡ **响应时间**: 按下`Ctrl+C`或`ESC`后，**最多50ms**即可停止执行
- 🎯 **稳定可靠**: 避免重复中断，资源清理完善
- 💬 **友好提示**: 提供明确的反馈信息

---

## 🎮 使用方法

### 1. Ask命令中断

```bash
# 执行查询
hkex-agent ask "查询腾讯控股最近的配售公告"

# 在执行过程中按 Ctrl+C
# 预期输出：
# ⚠️  中断信号已发送
# 💡 等待Agent停止（最多50ms）...
# ✅ 操作已取消
```

### 2. Chat命令中断

```bash
# 启动交互式对话
hkex-agent chat

You> 查询00700的配售数据

# 在执行过程中按 ESC 或 Ctrl+C
# 预期输出：
# ⚠️  中断信号已发送
# 💡 等待Agent停止（最多50ms）...
```

## 💡 最佳实践

### 正常使用
- ✅ 按一次`Ctrl+C`或`ESC`即可
- ✅ 等待50ms左右会看到中断提示
- ✅ 不需要重复按键

### 注意事项
- ⚠️ 在Windows上，ESC键监听可能不可用（使用`Ctrl+C`代替）
- ⚠️ 如果Agent已经接近完成，可能会在中断前就完成执行
- ⚠️ 连续快速按键可能被合并处理（避免重复中断）

## 🔧 技术细节

### 实现原理
```
用户按键 (ESC/Ctrl+C)
    ↓
信号处理器捕获
    ↓
设置中断标志
    ↓
主循环检查（每50ms）
    ↓
停止事件流
    ↓
显示中断消息
```

### 关键参数
- **中断检查频率**: 20ms（`asyncio.sleep(0.02)`）
- **队列超时时间**: 50ms（`asyncio.wait_for(timeout=0.05)`）
- **队列大小**: 10个事件
